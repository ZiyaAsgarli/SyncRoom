# Screenshot Capture Guide

Sanitized public screenshots have not been committed yet. Capture them from the production application using demonstration content and profiles that do not reveal private information.

Expected files:

- `syncroom-desktop-room.webp` - desktop room with the complete player and chat layout
- `syncroom-mobile-room.webp` - mobile portrait room with inline chat
- `syncroom-dashboard.webp` - owner dashboard and Guest Access section with placeholder identities
- `syncroom-drive.webp` - Google Drive playback without private filenames or file identifiers
- `syncroom-youtube.webp` - YouTube playback with the SyncRoom control overlay

Before committing a capture, verify that it contains no real email address, invite code, OAuth token, API key, Drive file ID, private filename, browser developer tools, Google Cloud console, or Supabase dashboard content.

Prefer WebP, crop browser chrome where practical, and keep desktop captures readable at roughly 1440 pixels wide. Mobile captures should use a representative 390 x 844 viewport.
