# Screenshot Assets

The public README currently uses these approved production captures:

- `syncroom-desktop-room.png` - desktop room with the complete player and chat layout
- `syncroom-mobile-room.jpg` - mobile portrait room with inline chat
- `syncroom-drive.png` - Google Drive playback without private filenames or file identifiers
- `syncroom-youtube.png` - YouTube playback with the SyncRoom control overlay

A dashboard capture is intentionally omitted until a fully sanitized replacement is available.

Before committing a capture, verify that it contains no real email address, invite code, OAuth token, API key, Drive file ID, private filename, browser developer tools, Google Cloud console, or Supabase dashboard content.

For future replacements, prefer WebP when it preserves readable UI text, crop browser chrome where practical, and keep desktop captures readable at roughly 1440 pixels wide. Mobile captures should use a representative 390 x 844 viewport.
